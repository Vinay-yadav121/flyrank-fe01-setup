# AI Assistant Instructions

## Project
This repository is for the FlyRank AI Frontend AI Engineering internship assignment FE-01: Environment and AI Toolchain.

## Technology Stack
- Node.js (LTS)
- npm
- Git and GitHub
- Visual Studio Code
- AI-assisted development tools

## Development Conventions
- Use clear, descriptive file and variable names.
- Keep documentation concise and accurate.
- Explain changes before making significant modifications.
- Avoid adding unnecessary dependencies.
- Never commit passwords, API keys, tokens, or `.env` files.
- Keep generated files and dependencies out of version control when appropriate.

## Git Conventions
Use Conventional Commits:
- feat: for new features or files that add functionality
- docs: for documentation changes
- chore: for configuration and maintenance tasks
- fix: for bug fixes

Examples:
- chore: initialize project repository
- docs: add project setup documentation
- chore: add gitignore and license

## Workflow
- Review existing files before editing them.
- Make small, focused changes.
- Verify commands and file changes before committing.
- Update the README when project setup instructions change.
